# 分组链式代理与自动选择

## 链式节点

1. 在规则模式打开右上角“链式代理”，选择目标代理分组。
2. 按入口到出口顺序点击至少两个实际代理节点，可用上移/下移调整顺序；点击“连接”。
3. 返回普通界面后，目标分组会包含并选中 `链式 A ⇒ B [分组名]`。关闭编辑器不会断开链式节点；可在该组选择其他节点，也可再选回链式节点。
4. 编辑器中的“删除已保存链”会删除该组的链式节点。若正在使用，请先回普通界面选择其他节点。

链节点为独立副本，不修改原始节点。上层分组引用目标分组时也会沿目标分组当前选择的链路转发。设置按配置文件保存。自动分组可能根据健康状态切换或拒绝固定不可用的链式节点。

## 分组模式、筛选和禁用

在普通界面的分组标题点击齿轮，可切换手动选择、故障转移或速度优先。切换模式时会将当前筛选结果作为该组候选快照；也可单独点击“应用当前筛选”。清空筛选再应用可恢复快照范围内的全部候选。自动组会按筛选后的候选进行选择。

右键节点可将它从该组的自动选择中禁用；手动选择模式下节点仍可选。打开分组齿轮菜单可重新启用禁用节点。禁用只影响当前分组，不影响其他分组中的同名节点。恢复原始分组会清除该组自定义模式、筛选快照和禁用记录。若订阅新增节点未包含在旧快照中，可先恢复原始分组，再重新筛选应用。
